# First-machine-learning-model
My first Machine Learning model using Python and Scikit-learn to predict ice cream sales from temperature using Linear Regression.
# First Machine Learning Model 🤖

This is my first Machine Learning model built using Python and Scikit-learn.

I used **Linear Regression** to learn the relationship between temperature and ice cream sales, then used the trained model to make a prediction.

## 📌 Project Overview

The model is trained on a small dataset:

| Temperature (°C) | Ice Cream Sales |
|------------------|-----------------|
| 20               | 200             |
| 25               | 250             |
| 30               | 300             |
| 35               | 350             |

After training, I tested the model with a temperature of **40°C**.

### Prediction

Temperature: 40°C
Predicted Sales: 400 Ice Creams
🧠 Model

I used Linear Regression from Scikit-learn.

The model learned:

Weight (w): 10
Bias (b): 0

So the learned relationship is:

Sales = 10 × Temperature
